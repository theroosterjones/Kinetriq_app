# Legacy app icon (v1) — ARCHIVED, do not use for the current build

These are the **old** Kinetriq app-icon assets that shipped before the
`k_logo_2.png` "K" logo icon replaced them (archived 2026-07-07).

Kept in case we want to revert or reuse them later. To restore, copy these
PNGs and `Contents.json` back into
`Sources/Assets.xcassets/AppIcon.appiconset/` and run `xcodegen generate`.

The current (new) icon source is `k_logo_2.png` in the repo root.
